# Progetto di Basi di Dati

## Descrizione del progetto

Il progetto è stato sviluppato nell’ambito del corso universitario di Basi di Dati e ha come obiettivo la progettazione e la realizzazione di una base di dati relazionale per una piattaforma di food delivery.

Il sistema gestisce clienti, ordini, ristoranti, piatti, ingredienti, ricevute, recensioni e richieste di assistenza.

## Modello della base di dati

La progettazione comprende:
- **Schema concettuale:** diagramma Entità-Relazioni.
- **Schema logico:** traduzione del modello concettuale in relazioni.
- **Schema relazionale:** implementazione delle tabelle e dei vincoli tramite SQL.

I diagrammi e la relazione completa sono disponibili nella cartella `docs/`.

## Tecnologie utilizzate

- MySQL
- LaTeX per stesura della relazione del progetto
- [miro.com](https://miro.com/) per la rappresentazione dello schema er
- [dbdiagram.io](https://dbdiagram.io/) per la rappresentazione dello schema logico
